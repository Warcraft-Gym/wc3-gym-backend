# Decision

The format select was removed from the season maps page. `Season.map_rules` and the stage's `best_of` keep every scoring rule and screen general, for community events.

# Why

A Bo5 is very unlikely for GNL: a Bo3 already strains everyone's calendar. Keeping the general support costs nothing and serves the events module.

# Consequences

- Do not add a best-of choice to a GNL screen, and do not reopen the Bo5 question.
- A community event that needs a longer format needs only the select back.
